# Visual Hierarchy

Priority:

1. Time
2. Focus State
3. Session Progress
4. Statistics
5. Settings

The current time/focus timer must dominate the screen.

# Typography

Rule:

Never use more than 2 font families.

Luxury watch typography relies heavily on restraint and spacing. Typography quality strongly affects perceived luxury and legibility.

---

## Primary Font

Recommended:

Inter

Alternative:

SF Pro Display

Weight:

300
400
500

Avoid:

700+
Black

---

## Display Numbers

Recommended:

Cormorant Garamond

Alternative:

Instrument Serif

Use only for:

* Timer
* Session Count
* Focus Score

# Design Philosophy

If a UI element does not improve:

* Time readability
* Focus immersion
* Mechanical elegance

Remove it.
